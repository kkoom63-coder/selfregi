재발급 QR 카메라 인식 시험

결제 완료 화면의 QR을 기존 방식과 개선 방식으로 나란히 그렸습니다. PC 화면에 띄우고 휴대폰 기본 카메라로 찍어 비교해 주세요.

휴대폰에서 열었습니다. 이 시험은 PC 화면에 띄워 놓고 휴대폰으로 찍는 시험입니다. PC에서 열어 주세요.

시험 방법

  1. PC 화면 밝기·배율은 평소대로 둡니다. 지금 화면 배율 (Windows 125%면 1.25)
  2. 휴대폰 기본 카메라 앱을 켜고 QR에서 약 30cm 떨어진 곳부터 천천히 가까이 댑니다.
  3. 3초 안에 화면에 링크 알림이 뜨면 O, 가까이 대도 안 뜨면 X를 누릅니다. 링크는 누르지 않아도 됩니다.
  4. 아이폰·갤럭시 둘 다 해 보고, 끝나면 「결과 복사」를 눌러 붙여 넣어 주세요.
개선 방식은 중복 이용권(?pass=, 약 140자)을 뺀 길이로 그립니다.
A

기존 방식

4px로 그린 그림을 220px로 줄이고 여백은 CSS 8px

B

개선 — 결제 완료 카드 안

정수 배율, 사방 4칸 여백, 카드 폭 안 최대 360px

C

개선 — 「QR 크게 보기」

전체 화면, 최대 720px. 버튼을 눌러 띄운 뒤 찍어 주세요
