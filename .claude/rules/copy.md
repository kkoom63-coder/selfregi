# 카피 규칙 (엄수)

- **슬로건**: "어려워서 못하는 게 아닙니다. 제대로 된 순서를 몰랐을 뿐입니다."
- **브랜드 미션**: "온라인으로 미리 끝내고, 등기소는 단 한 번" — 핵심은 인지부하 제거
- **비용 근거**: "서울 중위가격 아파트 15억원 기준, 법무사 수수료 약 120만원 절약"
  (2024.9 보수표 기준 각주 필수)

## 금지 표현

| 금지 | 대체 |
|---|---|
| 무조건 / 100% / 절대 / 보장 | 대부분 / 일반적으로 / 정확히 |
| 작성해드립니다 / 발급해드립니다 | 자동완성 도구 |
| 연결 / 알선 | 견적 장터 |

- 항상 "15~30만원", "Word 파일 다운로드", "자동생성/완성"으로 표기.
- 법령 근거는 제시하되 단정하지 않는다. **"최종 확인은 관할 등기소"** 톤 유지.
- 통계·수치에는 출처·시점 명기. **가짜 후기·가짜 로고 절대 금지.**
- 문체: 경어체(합니다/습니다체), 사실 중심, 드라이한 서술.

# 마케팅 전략

## 경쟁 지형

상위 블로그가 종합 how-to, 서류 체크리스트, 법무사 비용 비교를 장악하고 있다.
→ **정면승부 회피, 딥링크로 얹기.**

**빈틈(우리 기회): 반려 실무 디테일.** 대부분 한 줄만 언급하고 지나가는 것들.

- 반려 1위 사유 = 마스킹(주민번호 별표) + 주소 이력 누락
- 초본은 최근 5년이 아니라 **전체 이력**
- 잔금일로부터 60일 기한, 초과 시 과태료

## 콘텐츠 클러스터 3종

1. **절차 how-to** — 가이드 딥링크(`#g=키`)와 1:1 대응, SHOTS 텍스트 재활용으로 제작비 최소
2. **불안 키워드** (최우선) — 보정명령/반려/실수. 검색하는 사람 = 결제 직전 이용자
3. **비용·비교** — calculator 연계, 120만원 훅과 정합

## 채널

- 티스토리(selfregi.tistory.com) = 구글 SEO / 네이버블로그(blog.naver.com/seflregi24) = 네이버 SEO
- **블로그 = 유입 입구, 사이트 = 내비게이션**
- 기존 블로그 글에 가이드 딥링크 소급 삽입이 최저비용 1순위

## 블로그 작성 규칙

인라인 스타일 HTML, `pbt-` 프리픽스, 경어체, 단계별 번호, 말미에 서비스 링크 + 면책 2줄 고정.
네이버는 에디터 텍스트 붙여넣기(복잡 요소는 860px HTML 제작 후 캡처).

### '국내 부동산 Topic&Issue' 카테고리 디자인 표준

`pbt-wrap` 네임스페이스, 좌측 세로선 + 원형 dot 타임라인.
태그 색상은 **분야분류만**(세제/대출규제/공급대책/규제지역) — 강도 색 구분 금지.
타임라인 바로 아래 주황박스(`.pbt-reaction`) 시장반응 → 결론 밑줄+볼드 → 분야별 흰카드 전망 → 번호 체크리스트 → 최종 출처 정리박스 → 회색 footer 면책 2줄.

- 셀프등기24 서비스 광고·시리즈 글 링크는 **이 카테고리에 넣지 않는다.**
- 출처는 정부 공식 보도자료·언론보도만. **유튜브 콘텐츠 인용 금지.**

## 정치 이슈 취급

시사 이슈를 마케팅 훅으로 쓰지 않는다. 정치 트래픽은 전환되지 않고 수 주 내 꺼지며, 드라이한 톤과 충돌하고 논쟁 유입만 부른다.
이슈가 만든 **구조적 수요**(예: 대출규제 → 매도인 근저당 증가)만 근거로 쓴다.
